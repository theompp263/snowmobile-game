# Snowmobile Game

A browser-based 3D snowmobile riding game project.

## Planned features
- Open snowy terrain, hills, trails, and trees
- Visible snowmobile and rider
- Trail riding, hill climbing, and freestyle
- Customization for skis, track, suspension, paint, and body
- Weather, time of day, HUD, engine sounds, and saving

## Controls
- WASD: drive
- Arrow keys: lean
- Q/E: brace

Development is underway.
